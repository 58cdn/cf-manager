## 主题切换与偏好记忆

- 主题风格与深浅模式独立：`default`、`verdant` 均支持 light/dark，切换风格不改变已有深浅模式。default 保留实施前的布局、配色、密度和业务行为，不能仅保留旧颜色而替换原布局。
- 桌面顶部和移动导航面板提供有文字名称的主题选择器，登录页也提供同一入口。切换即时生效，不刷新、不重新挂载业务页面、不丢失表单、筛选、滚动和进行中的业务状态；Naive UI 弹窗、通知及 discrete API 同步更新。
- 主题偏好使用独立且带项目前缀的 localStorage 键 `cf-manager.ui-theme`，只接受 `default` 或 `verdant`。已有 `darkMode` 偏好继续兼容。启动时在首屏渲染前读取，登录成功时保留选择；刷新、关闭后重开、退出再登录均恢复已保存主题，退出登录不清除视觉偏好。
- 当前管理登录基于 API_SECRET，未提供独立用户身份。因此本期“登录后记住”按同一浏览器、同一源持久化实现，不宣称按 Cloudflare 托管账户隔离或跨设备同步；不使用 API_SECRET、Token 或它们的派生值作为偏好键，不新增后端用户体系。
- 存储不可用时仍允许内存中切换，并给出无法保存偏好的非阻断提示；无效或历史未知主题值恢复 default。通过共享主题状态、语义变量和主题作用域实现，避免复制整套页面和业务逻辑。

## 视觉规范

- 采用简洁运维控制台风格，保留绿色主色，不采用检索结果中的营销 Hero、CTA 或大面积玻璃效果。
- 浅色背景 #f5f7f9、卡片 #ffffff、正文 #1f2937、次级文字 #526071、主色 #16794b；深色背景 #111827、卡片 #1b2433、正文 #e5e7eb、次级文字 #a8b3c4、主色 #63d69b。主按钮前景按主题分别使用白色和深色，落地时检查实际对比度。
- 正文采用系统字体及中文字体回退，14px；页面标题 24px，区块标题 16px，辅助文字 12px；数字使用等宽数字。沿用 Ionicons，不加载远程字体。
- 间距按 4/8/12/16/24px，卡片圆角 12px、控件圆角 8px；常规按钮高 34px，密集表格保留紧凑密度。
- 交互反馈采用 150–200ms 颜色、边框与阴影变化，减少动态效果时关闭非必要动画。

## 实施顺序

1. **统一主题基础**：先保存 default 的桌面、移动端和深浅模式视觉基线；只移除已证明未使用且不影响 default 的模板样式。新增共享主题状态与配置，同时供 ConfigProvider、discrete API 和 CSS 使用。风格使用独立主题属性隔离；深浅模式沿用 app-dark，系统偏好只用于没有已存深浅偏好的首次初始化。先完成切换和持久化，再添加 verdant 的美化。
2. **应用外壳和登录页**：verdant 桌面保留可折叠侧栏，展开宽度 232px、折叠 64px；顶部 56px，显示当前栏目及主题风格、深浅模式、语言、退出操作。内容采用 flex 布局与明确滚动容器，避免依赖多重固定高度减法。verdant 登录页增加品牌区、说明和表单层级，保留原认证行为；default 保留原布局。
3. **仪表盘**：将现有账户数、AI 用量、Workers 请求量、浏览器时长展示为四个紧凑统计块，保留原统计口径和耗尽告警；下方依次为账户配额、审计日志。账户搜索、排序和刷新归为工具栏，日志筛选放在日志区域。保留账户密集展示能力和全部日志筛选。
4. **管理页面**：统一账户、DNS、Workers、存储、隧道、AI、浏览器渲染、商店和设置的页头与工具栏间距。表格使用统一背景、表头与容器边界；小屏仅表格局部横向滚动。复杂页面只调整外层布局及通用样式，保留专用编辑器、聊天区和表单功能。
5. **移动端与可访问性**：沿用 768px 切换点和悬浮导航，补齐按钮语义、可访问名称、展开状态、Esc 关闭与焦点返回。窄屏工具栏换行，内容避开悬浮按钮；图标沿用已有图标库，状态同时提供文字信息。中英文新增文案同步维护。
